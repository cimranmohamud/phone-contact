# Phone Contact App

**Creator:** Imran Mohamud

## Project Description

The Phone Contact App is a simple web application that allows users to save and manage phone contacts digitally instead of writing them manually.

## Features

- Add a new contact
- Save contact name and phone number
- Search contacts
- Edit existing contacts
- Delete contacts
- Store contacts using Local Storage so they remain after closing the browser

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript
- Local Storage

## Project Structure

```text
phone-contact/
├── index.html
├── script.js
└── README.md
```

## How to Run the Project

1. Open the project folder.
2. Open `index.html` in a web browser.
3. Click **Add Contact**.
4. Enter the name and phone number.
5. Click **Save**.
6. Use the search box to find contacts.
7. Edit or delete contacts when needed.

## How It Works

- The user enters a contact's name and phone number.
- JavaScript saves the contact to Local Storage.
- Saved contacts appear in the contact list.
- Contacts remain available even after refreshing or reopening the browser.

## Benefits

- Easy to use
- Saves time
- Reduces confusion
- Keeps contacts safely in the browser
